# Phase 05.1 Research: Proxy Pool & Admin Management

## 1. Requirement Analysis
**Requirement:** FARM-08 (Proxy Management)
**Goal:** Centralized proxy pool with auto-assignment and strict admin security.

## 2. Technical Strategy

### A. Proxy Pool Database Schema
New table `proxies` in `src/db/schema/farming.ts`:
```typescript
export const proxyStatusEnum = pgEnum('proxy_status', ['active', 'dead', 'maintenance']);

export const proxies = pgTable('proxies', {
  id: serial('id').primaryKey(),
  url: text('url').notNull(), // http://user:pass@host:port
  location: text('location'),
  provider: text('provider'),
  status: proxyStatusEnum('status').notNull().default('active'),
  usageCount: integer('usage_count').notNull().default(0),
  createdAt: timestamp('created_at').notNull().defaultNow(),
  updatedAt: timestamp('updated_at').notNull().defaultNow(),
});
```

### B. Assignment Logic
- **Constraint:** Maximum 3 accounts per proxy.
- **Selection:** `SELECT * FROM proxies WHERE status = 'active' AND usage_count < 3 ORDER BY usage_count ASC LIMIT 1`.
- **Trigger:** Assigned during `/farm_register` or `/farm_update` (if no proxy assigned yet).
- **Update:** When an account is assigned a proxy, increment `proxies.usage_count`. When an account is deleted/unassigned, decrement it.

### C. Admin Security (Milestone v2)
A new utility `src/utils/adminGuard.ts`:
```typescript
export const MILESTONE_V2_CONFIG = {
  AUTHORIZED_GUILD: '1465226886018760839',
  AUTHORIZED_USER: '898126643598606367',
};

export function isAuthorizedAdmin(interaction: BaseInteraction): boolean {
  return interaction.user.id === MILESTONE_V2_CONFIG.AUTHORIZED_USER || 
         interaction.guildId === MILESTONE_V2_CONFIG.AUTHORIZED_GUILD;
}
```

### D. Admin Commands
New directory `src/commands/admin/`:
- `/proxy add [url] [location] [provider]`
- `/proxy list`
- `/proxy remove [id]`
- `/proxy stats`

## 3. Implementation Plan
1.  **Schema Migration:** Create `proxies` table and add `proxyId` to `farming_accounts`.
2.  **Security Guard:** Implement `isAuthorizedAdmin`.
3.  **Proxy Management Logic:** Implement `ProxyService` for CRUD and assignment.
4.  **Admin Commands:** Implement slash commands using the security guard.
5.  **Integration:** Update farming registration to use the proxy pool.

## 4. Verification Strategy
- **Unit Tests:** `ProxyService` assignment logic, `isAuthorizedAdmin` logic.
- **Integration Tests:** DB migration and multi-account assignment limits.
- **Manual UAT:** Use admin commands to add proxies and verify auto-assignment during registration.
