# Phase 05.1 Context: Proxy Pool & Admin Management

## Phase Goal
Manage a centralized Proxy Pool and automatically assign proxies to User accounts to avoid Discord flagging. Implement Milestone v2 security for admin commands.

## Implementation Decisions

### 1. Proxy Pool Schema
A new table `proxies` will be created with the following fields:
- `id`: Primary Key.
- `url`: The proxy URL (e.g., `http://user:pass@host:port`).
- `location`: Geographical location (e.g., 'VN', 'US').
- `provider`: Proxy provider name.
- `status`: One of `active`, `dead`, `maintenance`.
- `createdAt` / `updatedAt`: Timestamps.

### 2. Assignment Logic: Static & Shared
- **Strategy:** Static Assignment. A proxy is assigned to a `farming_account` when the account is first created or when the token is updated.
- **Concurrency:** Up to **3 accounts per proxy**.
- **Selection:** When assigning, the system picks an `active` proxy with the lowest current usage count (must be < 3).

### 3. Database Changes
- Add `proxies` table.
- Modify `farming_accounts` to include `proxyId` (foreign key to `proxies.id`).
- Note: Keep existing `proxyUrl` in `farming_accounts` as a fallback or for manual overrides, but prioritize `proxyId` for pool management.

### 4. Admin Security: Centralized Utility
- Create a centralized utility function/middleware to enforce Milestone v2 security:
    - **Authorized Guild:** `1465226886018760839`
    - **Authorized User:** `898126643598606367`
- All proxy management and admin commands MUST use this utility.

### 5. Admin Commands Scope
- `/proxy_add`: Add a new proxy to the pool.
- `/proxy_list`: List all proxies with their status and usage counts.
- `/proxy_remove`: Remove a proxy (deactivate it).
- `/proxy_stats`: Show global proxy health and capacity.

## Verification Plan

### Automated Tests
- Unit tests for the assignment logic (ensure 1:3 limit is respected).
- Integration tests for DB schema and migrations.
- Mock tests for security utility.

### Manual Verification
- Add a proxy via `/proxy_add`.
- Register a farming account and verify it gets assigned the proxy.
- Verify that a 4th account cannot be assigned the same proxy if the limit is reached.
- Verify admin commands are blocked for unauthorized users/guilds.
