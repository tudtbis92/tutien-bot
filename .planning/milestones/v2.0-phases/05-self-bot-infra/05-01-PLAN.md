       - `plan_type`: text ('free', 'basic', 'premium').

  <action>
    Implement `EncryptionService` using `node:crypto` (per D-03):
    1. Use `aes-256-gcm` algorithm.
    2. IV should be 12 bytes (`randomBytes(12)`).
    3. Implement `encrypt(text, keyVersion)` and `decrypt(encryptedData, iv, tag, keyVersion)`.
    4. Handle key lookup from an environment variable `FARM_ENCRYPTION_KEYS` which should be a JSON string like `{"1": "hex_key_32_bytes", "2": "..."}`.
    5. Ensure the service handles missing keys or invalid JSON gracefully.
