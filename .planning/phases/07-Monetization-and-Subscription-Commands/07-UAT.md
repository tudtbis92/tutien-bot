Verify that users can purchase, upgrade, and manage subscriptions for the OwO farming service, and that the system correctly enforces these subscriptions.

### 1. Subscription Purchase (Basic Plan)
**Goal:** Verify user can buy a Basic plan using Linh Thạch.

**Goal:** Verify user can upgrade from Basic to VIP.

### 3. Subscription Expiry & Enforcement
**Goal:** Verify the system stops farming when a subscription expires.

**Goal:** Verify Basic plan users cannot use VIP features.
- [x] User with Basic plan attempts to enable VIP-only features.
