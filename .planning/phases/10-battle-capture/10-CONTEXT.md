# Phase 10: Battle & Capture - Context

**Gathered:** 2026-08-13
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 10 closes the first complete vertical loop of the Tam Quốc Collection: starter → travel → encounter → **battle → capture → collection**. It is the first "is the game fun?" validation point of the milestone. Delivers the seeded/replayable battle engine (pure-rand), the capture service with server-authoritative % rolls + per-encounter pity, the IV roll + free starter onboarding (the ONLY faucet), and the `/sanguo heroes` collection + `/sanguo hero` active-companion view.

**Requirements in scope:** TQC-10 (battleEngine seeded/replayable + sanguo_battles records + solo battle), TQC-11 (captureService + crypto RNG + % displayed + pity + audit log incl. failures), TQC-12 (IV 0-31 roll at capture + free starter onboarding = only faucet), TQC-13 (collection view + map position).

**Hard gate before content ships:** the D-18 economy re-sign — `docs/economy-budget.md` MUST be updated + re-signed with the Phase 10 5-tier capture-fee values (assuming pull-driven encounter supply ≤ 20/hr) as a plan task.

**Not in scope:** XP/leveling, evolution, shop + healing items, skills (MP spend), hồn ngọc/dupe, legion chemistry, boss drops — all Phase 11. Anti-abuse bot detection — Phase 12. Capture tiers 4-5 special items — Phase 11/events.

</domain>

<decisions>
## Implementation Decisions

### Battle Entry & Hero Stats (TQC-10)

- **D-01:** **Encounter-initiated battle replaces the Phase 9 ack button (D-25).** The "Tiếp tục hành trình" ack becomes the "Chiến đấu" button on the encounter embed. `/sanguo battle` exists as the **free spar/practice** surface (D-17) — it never spawns a capturable encounter, so the ≤20/hr encounter supply cap is never bypassed. — **Reversibility:** one-way — inverts the D-25 ack contract wired into `travelCheckInService` + `interactionCreate`.
- **D-02:** **Base stats = 8 columns added to `heroes`: STR/AGI/INT/MOV/LEA/CHA (matching the 6 IV stats) + HP + MP, plus a `rarity` column (1-5).** Seeded via content research (same class of work as TQC-09). `combatStat = base + IV`; **HP/MP = base only — IV never adds HP** (IV set stays exactly 6 stats). — **Reversibility:** costly — schema migration + full seed research pass; every battle/capture formula depends on these columns.
- **D-03:** **Wild hero stats = base + IV rolled at encounter time; the rolled IV is stored in the battle record** so the battle stays replayable and each encounter's difficulty varies. — **Reversibility:** reversible.
- **D-04:** **HP persists per owned hero across battles.** On loss the encounter flees (no capture). The player switches the active companion via `/sanguo hero`; healing is items = Phase 11 (TQC-16). If the active hero is fainted (HP 0): encounters still roll but the battle is BLOCKED with a "đổi hero đồng hành trước" prompt (same for spar). All heroes at 0 HP → no further battles (accepted soft-lock by design).

### Battle Engine & Replay (TQC-10)

- **D-05:** **Battle formula contract (locked):** `combatStat = base + IV`; HP/MP base-only; **turn order = MOV desc**; tie → compare AGI, still tie → **attacker first**; **attack type by class** — STR: `vanguard`/`cavalry`/`archer`, INT: `spellcaster`/`schemer`, MAX(STR,INT): `vu_co`/`thu_binh`/`cong_binh`; **damage = max(atk − def, 1)**; hit/crit derive from AGI (principle locked: AGI ↑ hit chance + crit, defender AGI ↓); **crit doubles damage**; **round cap (~20, exact value agent) → winner = higher total damage dealt; tie → higher remaining HP%**; LEA/CHA unused in Phase 10 (buff/debuff reserved for Phase 11 chemistry). — **Reversibility:** costly — formula is the balance contract; retuning later touches engine + capture balance.
- **D-06:** **Replay model: seed + input, recompute.** Battle seed is generated by `crypto.randomInt` (so the outcome stays unpredictable); all in-battle rolls then ride **pure-rand** seeded by it (pure-rand is battle-only per milestone decision — never for player-facing capture/encounter rolls). `sanguo_battles` stores seed + both heroes' full stat input; `roundLogs` jsonb computed at battle time; **replay = re-run engine(seed, input)**. `pure-rand` is NOT yet a dependency — must be added to package.json. — **Reversibility:** costly — the stored-record contract + dependency choice.
- **D-07:** **Battle log = full turn-by-turn log rendered in a single embed**, round cap keeps it bounded. — **Reversibility:** reversible.

### Capture Fee, Rarity & Pity (TQC-11 + D-18 gate)

- **D-08:** **Rarity is a real column on `heroes` (1-5), seeded with the base-stats research.** Rarity drives capture chance (rarer = lower base capture), flee rate (rarer = higher flee), and fee tier. — **Reversibility:** costly — part of the D-02 content pass; rarity numbers feed the economy re-sign.
- **D-09:** **Capture fee = 5 tiers**, each tier has a fee + a capture-chance multiplier ("mỗi tier sẽ tăng tỷ lệ bắt khác nhau"). **Capture UI shows 3 tier buttons (direct fee payment)**; **tiers 4-5 only appear when the player holds a special item** (events / Phase 11 shop). Engine + schema model all 5 tiers; Phase 10 activates 1-3. Fee always goes through `wallet.deductBalance` (D-03 Phase 8). — **Reversibility:** one-way — this is the D-18 economy contract; rebalancing the tier values requires a new economy sign-off.
- **D-10:** **Capture flow:** battle win → "Bắt" button → capture view (current % + 3 tier buttons + "Bỏ qua" retreat). Roll once via crypto RNG against the DISPLAYED %. Fail → a **flee roll** fires (flee chance by rarity; rarer = more likely to flee). Flee → hero gone, encounter resolved, travel resumes. No flee → retry allowed (fee each attempt; % recalculated with pity). — **Reversibility:** costly — the retry/flee loop is wired through `travelCheckInService`'s pending-encounter state.
- **D-11:** **Pity = per-encounter bad-luck protection:** each failed attempt adds +X% capture chance for the NEXT attempt on the same hero; resets on success, flee, or retreat. — **Reversibility:** reversible.
- **D-12:** **Hidden-mechanics contract (user, hard):** IV numbers and rarity are ABSOLUTELY never shown on any UI — only the **IV grade** (Hoàng Kim / Hồng ngọc / Lam cấp / Lục cấp / Hôi cấp). The capture % shown before attempting (SC2) is the exact computed chance and the single displayed number. — **Reversibility:** one-way — a user-facing content contract; surfacing raw numbers later needs a design change.
- **D-13:** **Boss thường encounters (D-14) ARE capturable** after a win — at a low rate consistent with high rarity. — **Reversibility:** reversible.

### Starter & Collection UX (TQC-12/13)

- **D-14:** **Starter onboarding lives inside `/sanguo heroes`:** when the collection is empty the command renders the starter picker (faucet = one free hero, D-19 exception). Starter set 1: **Tào Tháo, Lưu Bị, Tôn Kiên**. If the user invokes `/sanguo heroes` 3 times without picking, from the **4th call the pool rotates to set 2: Trương Giác, Viên Thiệu, Đổng Trác** (the "hidden option" = the second set, no 4th option in set 1). The chosen starter becomes the active companion. — **Reversibility:** reversible — starter roster is seed data; rotation is a counter in the command.
- **D-15:** **`/sanguo heroes` = owned-only collection with a zone filter** (select zone), each hero one line: emoji + name + tier + IV grade; active companion highlighted. — **Reversibility:** reversible.
- **D-16:** **New subcommand `/sanguo hero`** = per-hero detail + "chọn làm hero đồng hành" (active companion switch — required by D-04 HP persistence). Deliberately separate so Phase 11 (level/evolution) extends it. — **Reversibility:** reversible.

### Spar / Retreat / XP

- **D-17:** **Spar/practice = `/sanguo battle` vs a random real hero (base + IV, no capture).** Free, no fee, no real HP loss, no reward. Blocked when the active hero is fainted (switch prompt, same as D-04). — **Reversibility:** reversible.
- **D-18:** **Retreat is allowed on every encounter/capture view** ("Bỏ qua / Rút lui"): the wild hero departs, the pending encounter resolves, travel resumes. The encounter cap is unaffected (cap counts roll hits, not resolutions). — **Reversibility:** reversible.
- **D-19:** **No XP/leveling in Phase 10 — all heroes stay level 1** (`user_heroes.level` remains static). Level/evolution stat models are Phase 11 (deferred below). — **Reversibility:** reversible.

### Economy gate

- **D-20:** **D-18 re-sign is an in-phase plan task (BLOCKING):** `docs/economy-budget.md` MUST be updated + re-signed with the 5-tier capture-fee values (fees + capture multipliers, priced by the researcher) assuming pull-driven encounter supply (≤20/hr), BEFORE any Phase 10 content ships. Net-sink/neutral (D-19 Phase 8) stays the hard constraint; the free starter is the only faucet. — **Reversibility:** one-way — the milestone's economic guardrail.

### the agent's Discretion

- Exact round cap number (~20) and battle embed layout / customId naming (`sanguo:battle:*`, `sanguo:capture:*`).
- Capture fee tier values + capture multipliers (researcher prices them for the D-20 re-sign).
- Flee rate values per rarity; pity increment value (X%); IV roll distribution (uniform 0-31 default).
- Base-stats + rarity values per hero (research content); starter set roster confirmation (names locked in D-14).
- Where current HP is stored (e.g., `user_heroes` HP column) and the active-companion user-state shape.
- `sanguo_battles` schema extension (seed + input columns) beyond the Phase 8 base (userId, status, roundLogs).

<specifics>
## Specific Ideas

- **"IV là data ẩn, tuyệt đối không được hiển thị trên bất kỳ UI nào, chỉ hiển thị grade. rarity cũng vậy"** — hard hidden-mechanics rule (D-12).
- **"người chơi có thể đổi Hero khác đang có, hoặc hồi máu bằng item (Phase 11). Nếu không thì sẽ không thể encounter tiếp"** — HP persistence + active-companion switch consequence (D-04).
- **"có thể retry, nhưng sau mỗi lần fail lại random để xác định flee, tỷ lệ này cũng phụ thuộc rarity, rarity càng hiếm thì tỷ lệ flee càng cao"** — capture retry + flee-roll design (D-10).
- **"có 5 tier capture fee, mỗi tier sẽ tăng tỷ lệ bắt khác nhau"** + **"tại UI capture thêm 3 button tương ứng với 3 tier đầu, 2 tier sau chỉ hiển thị khi có item đặc biệt (nhận được trong sự kiện, hoặc mua với ở shop)"** — 5-tier capture model (D-09).
- **"3 hero: Tào Tháo, Lưu Bị, Tôn Kiên + 1 option ẩn... lần gọi lệnh thứ 4 sẽ ra 3 starter khác là: Trương Giác, Viên Thiệu, Đổng Trác"** — starter rotation (D-14; "hidden option" = set 2, no 4th option).
- **"so tổng sát thương gây ra rồi mới so HP%"** — round-cap resolution (D-05).
- Base stats == species stats (giống Pokémon base), IV == individual variance rolled at capture; `combatStat = base + IV`; HP/MP base-only — locked (D-02/D-05).

</specifics>
