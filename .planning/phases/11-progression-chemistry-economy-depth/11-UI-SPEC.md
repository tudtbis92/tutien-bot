# Phase 11 — UI Design Contract: Progression, Chemistry & Economy Depth

> Visual and interaction contract for the Phase 11 frontend surface. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Medium note:** The Phase 11 "frontend" is the **Discord embed + message-component surface** (discord.js 14.26.2) — identical medium to Phase 10. NO web frontend, NO React/Next.js/Vite, NO shadcn. **This contract EXTENDS the Phase 10 UI-SPEC (`10-UI-SPEC.md`, approved 2026-08-13) — it does NOT restart the design system.** Every Phase 10 budget, color key, customId shape, and hidden-mechanics rule carries forward verbatim; Phase 11 only ADDS new surfaces, namespaces, and copy keys on top of the locked baseline.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual discord.js embed/component builders — no shadcn, no web stack) |
| Preset | not applicable |
| Component library | none (Discord-native: `EmbedBuilder`, `ButtonBuilder`, `StringSelectMenuBuilder`) |
| Icon library | `src/ui/theme.ts` `EMOJI` constants (unicode) + `heroEmoji()` animated custom emoji (`<a:name:id>`, D-21) + **content-driven emojis** (per-item / per-skill / per-formation emoji columns in seed data — never theme constants) |
| Font | Discord client font (gg sans) — NOT controllable; contract constrains character budgets instead |
| Theme source | `src/ui/theme.ts` — **ALL embed colors MUST come from `COLORS`; never hardcode hex** (Phase 8/9/10 rule). **COLORS is unchanged — zero new color keys, zero new hex values** |
| Embed contract | Every embed: `.setFooter(embedFooter(shardId))` + `.setTimestamp()`; title starts with a leading emoji (established convention) |
| Localization | All UI strings via i18next `sanguo:` namespace (VI/EN/ZH-CN, zero-hardcoded lint); hero/zone/item names from DB per-locale columns (D-07) — skill names are i18n keys (`sanguo:skills.*`), never DB names |
| Hidden mechanics | D-12 hard rule carries; **Phase 11 additions to the never-render list**: chemistry raw points + buff % (D-19), boss capture-result weight distribution (D-28), skill rarity weights (D-30), wild-level distribution percentages (D-33). **Phase 11 additions to the VISIBLE list**: hồn ngọc balances and costs, level costs, skill MP costs (all spendable resources — visible like Linh thạch fees) |

**Phase 11 theme addition (the ONLY theme change, flagged):** `EMOJI.HON_NGOC: '🧿'` — the hồn ngọc currency glyph. It MUST be distinct from `💎` (LINH_THACH) and from `💠` (already used by the main-game material `linh_khi_tinh` in `src/db/seed.ts:68` — verified clash). All hồn ngọc amounts render as `**{{n}}** 🧿`. No other theme.ts change.

Sources: `src/ui/theme.ts`, `src/db/seed.ts:68` (💠 clash verification), `10-UI-SPEC.md` (baseline), `11-CONTEXT.md` D-01..D-36.

## Spacing & Layout Budgets (Discord-native)

Web pixel spacing does NOT apply. **All budgets below are hard Discord API limits unless marked (contract).** Phase 10 budgets carry verbatim; new Phase 11 budgets:

| Token | Value | Usage / Constraint |
|-------|-------|--------------------|
| ActionRow slots | ≤ 5 components/row, ≤ 5 rows/message | **Copy-detail surface: 3 rows max** — copy select row + page-button row + action-button row (selects and buttons NEVER share a row, CR-09-01) |
| Select+button rows | 1 row each | CR-09-01 (live-verified): a select menu and buttons MUST be in separate ActionRows |
| Legion assembly rows | ≤ 4 rows | formation select / slot-pick select / hero-pick select / save button = 4 rows (≤ 5) |
| Shop tabs | 2 buttons in ONE row | 💎 Linh thạch + 🎁 Sự kiện toggle buttons (researcher decision R-1: buttons, not select — fixed 2 options, tab-like) |
| Copy selector options | ≤ 25 per page | Discord select-menu limit (D-04); >25 copies → page buttons (⬅️/➡️, one row, ≤ 5) + page counter in the copy-list field |
| Embed fields | ≤ 25 per embed | Legion view uses 2 fields (Chủ lực 3 lines + Hỗ trợ 9 lines); copy list uses ≤ 2 fields (list + page counter) |
| Battle log rounds | ≤ 20 (contract, extended from D-05) | Legion 3v1 rounds have up to 3 main actions + support-effect lines → per-round ≤ ~100 chars → log ≤ ~2,000 chars, safely under 4,096 |
| Hero-pick select options | ≤ 25 | Class-matched owned heroes for the selected slot, paged at 25 (same paging pattern as copy selector) |
| Edit-reply components | `components: []` on every `editReply` | CR-09-03 (live-verified PATCH merge semantics) |
| embedFooter | always appended | `Tu Tiên Bot • Shard {id}` — every embed |

Exceptions: none — all Phase 11 surfaces sit inside these budgets by construction.

## Color

**COLORS is unchanged (Phase 10 lock — extend nothing).** New Phase 11 surfaces map to EXISTING keys only:

| Role | Key / Hex | Usage in Phase 11 |
|------|-----------|-------------------|
| Dominant — sanguo | SEASON `0x8B5CF6` | Shop (both tabs), bag, legion assembly, copy selector, hero detail (extended), heroes filters, convert / level / evolve / reroll surfaces — every non-boss sanguo surface |
| Accent — boss | GOLD `0xF59E0B` | Boss encounter variant (D-24 named general) + boss capture view ONLY — Phase 10 lock carries verbatim |
| Accent — success | SUCCESS `0x10B981` | Convert done, level up, evolve done, reroll done, shop purchase success, bag-use success, legion saved, battle win, boss item drop |
| Accent — failure | DANGER `0xEF4444` | Insufficient-hồn ngọc / insufficient-Linh thạch / insufficient-dupes errors, class-mismatch error, battle loss, max-level attempt |
| Accent — caution | WARNING `0xF59E0B` | Incomplete-legion caution (save allowed), soft-lock warnings — setback, not loss |
| Neutral | NEUTRAL `0x6B7280` | No new usage — remains spar-only (Phase 10 lock) |

**Accent reserved for (10%, unchanged):** boss variant (GOLD), outcome states (SUCCESS/DANGER/WARNING), spar (NEUTRAL). Accent colors are **never** used on shop/bag/legion/progression surfaces (SEASON covers them). All prices and hồn ngọc costs render as glyph + bold number in labels — a price, not a color accent.

**Never-render contract (D-12 + Phase 11 additions, hard):** IV stat numbers, IV sum, rarity number, capture formula, flee %, pity count, tier multipliers, base stats, **chemistry raw points and buff % (D-19), boss capture-result weight distribution — the t0 95% / t1 4.98% / t2 0.02% roll MUST never leak (D-28), skill rarity weights (D-30), wild-level distribution percentages (D-33)**. Only the IV grade (iv_grade.* keys), the single capture %, the chemistry TIER label + link presence, the rolled level number, the revealed stars/grade/level of a captured copy, and spendable costs (hồn ngọc 💠🧿, Linh thạch 💎, MP) may appear.

Sources: `src/ui/theme.ts`; `10-UI-SPEC.md` §Color; `11-CONTEXT.md` D-12/D-19/D-28/D-30/D-33.

**Interaction contract (copy detail, D-04 flow):** copy select press → `editReply` re-renders the hero embed with action buttons targeting the CHOSEN copy (buttons carry `userHeroId`); hero with 1 copy skips the select and renders actions directly. Action presses charge on press (Phase 10 capture-fee pattern) — no confirm dialogs exist on Discord; cost/yield in the label + consequence in the result embed.

**Interaction contract (legion assembly, R-10):** formation select (row 1) → slot-pick select (row 2, 12 slots) → hero-pick select (row 3, class-filtered) → save button (row 4). Each press re-renders the legion embed with updated assignments + chemistry lines. Sequential inline flow, all `deferReply` → `editReply`.

Button visuals: emoji via `.setEmoji()` with the `EMOJI_NOT_FOUND` → name-only guard (map.ts:98 pattern); labels plain text (CR-09-02).

- **Boss capture result reveal shows only the ROLLED copy** (stars + grade + level via `capture.captured_copy`) — the t0/t1/t2 weight distribution is never rendered (D-28).
- **Skill rarity weights never render** (D-30); skills render by name + MP cost (MP cost is a spendable resource — visible).
- **Wild-level distribution percentages never render** (D-33); the rolled level renders as `Lv{{n}}` on the encounter line.
- **Booster owned state is visible** (`convert.booster_hint`) — it is an owned consumable, not a hidden mechanic.
