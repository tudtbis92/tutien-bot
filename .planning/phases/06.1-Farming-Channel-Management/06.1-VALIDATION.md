# Phase 06.1: Farming Channel Management - Validation

## Must-Have Truths Verification

| Truth | Verification Method | Automated Command |
|-------|---------------------|-------------------|
| A private channel is created in the auth server on setup. | Integration Test | `npm test src/services/farming/__tests__/channelService.test.ts` |
| The channel is only visible to main bot, owner, and self-bot (D-03). | Integration Test | `npm test src/services/farming/__tests__/channelService.test.ts` |
| The self-bot automatically starts farming in the assigned channel. | Worker Test | `npm test src/workers/__tests__/selfBotWorker.test.ts` |
| Updating settings/token triggers a restart (D-05). | Worker Test | `npm test src/workers/__tests__/selfBotWorker.test.ts` |
| The channel is deleted if the farming account is removed (D-06). | Integration Test | `npm test src/services/farming/__tests__/channelService.test.ts` |

## Task-Level Verification

### Task 1: Database Schema Update & Config Setup
- **Check DB Schema:** `npm run db:check`
- **Check Config:** `npm test src/__tests__/config.test.ts` (if exists) or manual check of `src/config.ts`.
- **Check .env.example:** `grep -E "AUTH_SERVER_ID|FARMING_CATEGORY_ID" .env.example`

### Task 2: Channel Management Service & Command Integration
- **Unit/Integration Test:** `npm test src/services/farming/__tests__/channelService.test.ts`
- **Command Integration:** Manual verification by running `/farming setup` in a dev environment and checking for channel creation.

### Task 3: Worker Integration & Reactivity
- **Worker Logic Test:** `npm test src/workers/__tests__/selfBotWorker.test.ts`
- **End-to-End Reactivity:** Manual verification: Update `channelId` in DB and verify worker logs indicate a restart.

## Final Success Criteria
- [ ] `farming_accounts` table has `channel_id` column.
- [ ] `ChannelService` successfully uses `broadcastEval` to manage channels.
- [ ] Discord channels are private and correctly scoped.
- [ ] Self-bots farm ONLY in their assigned channels.
- [ ] Channel deletion is consistent with account lifecycle.
