# Phase 06.1: Farming Channel Management - Context

## Goal
Tự động gán và tạo channel farming riêng tư cho user trong `auth_server` sau khi self-bot login thành công. Điều này giúp cô lập hoạt động farm của từng user và cung cấp không gian để user theo dõi bot.

## Decisions

- **D-01: First-class `channelId` column** — Add `channelId` as a `text` column in `farming_accounts` table (null by default).
- **D-02: Private Channel per User** — Every farming account gets exactly one private text channel in the `auth_server`.
- **D-03: Channel Ownership/Access** — Channel is visible to:
  1. Main Bot (Admin/Manage)
  2. Real User (Read/History)
  3. Self-Bot (Send/View)
- **D-04: Cross-Shard Management** — Use `client.shard.broadcastEval` to ensure channel creation/deletion works across shards, as the `auth_server` may reside on any shard.
- **D-05: Reactive Workers** — `SelfBotWorker` must detect changes in `channelId` or `settings` from `START_BOTS` payloads and restart the `FarmingLoop` if a bot is already running but its configuration has changed.
- **D-06: Automatic Cleanup** — When a user removes their token or the account is deleted, the associated Discord channel must be deleted.

## Infrastructure (Auth Server)
- **Guild ID:** `1465226886018760839` (Authorized Guild).
- **Category ID:** `1512003097583554641` (Farming category).
- **Naming Convention:** `farming-{userId}`.

## Workflow & Trigger
- **Trigger:** Channel chỉ được tạo/gán sau khi `SelfBotWorker` báo cáo trạng thái `READY` (Login thành công).
- **Flow:**
    1. `SelfBotWorker` login -> gửi `STATUS: READY` về `SelfBotMaster`.
    2. `SelfBotMaster` kiểm tra `farmingChannelId` trong DB cho user đó.
    3. Nếu chưa có:
        - Main Bot tạo channel trong category chỉ định thông qua `broadcastEval`.
        - Thiết lập permissions cho Main Bot, Real User và Self-Bot (ID decode từ token).
        - Lưu `farmingChannelId` vào table `farming_accounts`.
    4. `SelfBotMaster` gửi message IPC cho `SelfBotWorker` để cập nhật `settings.channelId`.
    5. `SelfBotWorker` bắt đầu `FarmingLoop` trong channel vừa gán.

## the agent's Discretion
- **Error Handling:** If channel creation fails, log the error. `FarmingLoop` will not start without a `channelId`.
- **Token Decoding:** Use the Base64 decoding of the first segment of the token to extract the Self-Bot's Discord ID for permission overwrites.

## Deferred Ideas
- **Multiple Categories:** Support for rotating categories once the 50-channel limit is reached is deferred.
- **Multi-Server Farming:** Restricted to a single `auth_server` for now.
