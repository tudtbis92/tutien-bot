### 2. Proxy Pool Management (CRUD)
- **Goal**: Verify ability to add, list, and remove proxies.
- **Steps**:
    1. Run `/proxy add url:http://test-proxy:8080 location:VN provider:Test`.
    2. Run `/proxy list` and verify the proxy is present and `active`.
    3. Run `/proxy remove id:<id_from_list>`.
    4. Run `/proxy list` and verify it is gone or marked as `dead`.
- **Expected Result**: Proxy is added, listed correctly, and removed/deactivated successfully.
- **Actual Result**: User confirmed CRUD operations are functional.
- **Verdict**: PASS
