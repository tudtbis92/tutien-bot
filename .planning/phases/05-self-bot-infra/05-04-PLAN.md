  <files>src/commands/game/farming.ts, src/events/interactionCreate.ts</files>
  <action>
    Implement interaction logic (per D-04):
    1. Button Handler (`farming:start`):
       - Check user eligibility (stub check against `farming_subscriptions`).
       - If eligible, show a Discord Modal (`farming:token_modal`) with a single text input for the token.
    2. Modal Handler (`farming:token_modal`):
       - Retrieve token from input.
       - Validate token format (basic regex/length check).
       - Encrypt token using `EncryptionService` with the current `ACTIVE_FARM_KEY_VERSION`.
       - Upsert into `farming_accounts` table:
         - `userId` (references users.id based on interaction.user.id)
         - `encrypted_token`, `iv`, `tag`, `key_version`.
         - `status`: 'active'.
       - Trigger immediate worker loading/updating by sending an IPC message to ShardingManager:
         `process.send!({ type: 'FARMING_ACCOUNT_UPDATED', userId: interaction.user.id });`
       - Send an ephemeral confirmation message to the user.
    3. Register these handlers in the main `interactionCreate` event.
  </action>
  <verify>
    <automated>node --check src/events/interactionCreate.ts</automated>
  </verify>
  <done>Full provisioning loop from button click to encrypted storage and Master IPC notification implemented.</done>
