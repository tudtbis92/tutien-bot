<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Database → Master | Tokens are decrypted in Master memory before being sent to Workers |
| Master → Workers | IPC channel is the only path for decrypted tokens |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | Master Process Memory | mitigate | Decrypt tokens only at the last moment before sending to worker; Ensure worker processes are properly isolated. |
| T-05-04 | Spoofing | Worker Process | mitigate | Master strictly controls worker spawning; IPC communication is restricted to the parent-child relationship. |
</threat_model>
