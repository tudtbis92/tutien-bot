  <files>src/workers/selfBotWorker.ts</files>
  <action>
    Create the worker entry point (per D-01, D-02):
    1. Setup `process.on('message')` to listen for IPC commands from Master.
    2. Implement a `WorkerManager` class inside the script to manage a `Map<string, Client>` (botId -> Client).
    3. Commands to support: `START_BOTS` (payload: Array of { id, token, proxy }), `STOP_BOTS` (payload: Array of ids).
    4. For each client:
       - Disable all caches (per Pitfall 2): `makeCache: Options.cacheWithLimits({ MessageManager: 0, GuildMemberManager: 0, ... })`.
       - Support proxying if `proxy` is provided:
         * Use `ProxyAgent` from `proxy-agent` under `ws.agent` for the Gateway WebSocket connection.
         * Set `http.agent` to the proxy URL string for REST API requests.
       - Emit status updates back to Master via `process.send({ type: 'STATUS', botId, status, error })`.
    5. Handle process cleanup on `SIGTERM`.
  </action>
  <verify>
    <automated>node --check src/workers/selfBotWorker.ts</automated>
  </verify>
