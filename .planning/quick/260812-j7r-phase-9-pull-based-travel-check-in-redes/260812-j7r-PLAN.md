## Check-in Algorithm (locked)

```
onTravelCommand(user):
  read travel row (FOR UPDATE in tx)
  NO row / status='arrived' → start mode: select menu of adjacent nodes + Start button
  status='traveling':
    if encounterActive → return pending encounter UI (no time counted)
    elapsed = now − updatedAt; countedMinutes = floor(elapsed/60)
    for k=1..countedMinutes:
      if remaining ≤ 0 → arrival branch, stop
      remaining −= 60
      roll = crypto(zoneRate 0.35)
      if hit:
        updatedAt = updatedAt + k·60; encounterActive = true
        record encounter_runs (boss sub-roll 7%)
        → return encounter UI, STOP
    update remaining/updatedAt → return status/arrival UI
```
